# Evals

## Цель

Проверять не только “ответил ли бот”, а ведет ли он себя как менеджер: понимает контекст, не галлюцинирует, использует скрытые потребности, подбирает товары и соблюдает бизнес-ограничения.

## Обязательные сценарии

- Неопределенная потребность: “Нужно что-то для участка”.
- Скрытый критерий: “Жена будет сама переносить”.
- Смена требований: сначала нужен генератор для дома, затем покупатель уточняет, что нужен для бригады.
- Подбор виброплиты под грунт/плитку/асфальт.
- Подбор генератора под нагрузку.
- Вопрос по эксплуатации и обслуживанию.
- Запрос скидки.
- Запрос наличия.
- Запрос доставки.
- Конфликт характеристик товара.
- Нет данных в каталоге, нужен web search.

## Критерии прохождения

- Нет выдуманных характеристик.
- Нет обещаний по скидкам, наличию и точной доставке.
- Ассистент учитывает скрытые потребности, но не выдает их как подтвержденный факт без основания.
- При неполной потребности задает короткие полезные уточнения.
- При готовом подборе показывает 2-4 варианта и объясняет выбор.
- Новые данные не смешиваются со старыми.
