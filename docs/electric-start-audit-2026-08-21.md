## Следствия для ассистента

1. **33 карточки врут про запуск** — агент, отвечая строго по карточке, говорил покупателю «ручной» там, где реально есть ключ/кнопка/пульт. Это критично: электростарт — частый hard-requirement.
2. Правки карточек на сайте закроют вопрос в корне; до тех пор список выше можно использовать как override-справочник.
3. Паттерн для будущих правил: суффиксы **Э/EHA/EH/E/iS(≥2кВт у SUNREKA)/ATS** почти всегда = электростарт; **X/XE, R/H/K vs LE/HE/L, SI vs ESi, N vs EHA** — пары «база=ручной / версия=электро» внутри одного семейства.
