## Дополнительные cross-layer closes

- Feedback close-race: capability, active/non-stale session lock, message metadata update и audit-event insert выполняются одним repository statement; route-level restore→mutation race удалён. Contract находится в `tests/chatSessionLifecycle.test.ts` и `tests/conversationRepository.test.ts`; real PostgreSQL `close_vs_feedback` с row-lock barrier и readback прошёл.
- Exact-ID legacy memory bypass: consumer отклоняет name-only/null-product fact, когда selection знает exact product IDs. Это дополняет H3 repository lookup и не оставляет producer/consumer обхода.
- Latest lead offer semantics: old lead offer после нового обычного assistant answer не открывается (`raw/session-turn-builder.md`, initial 1 failed/17 passed → GREEN), а новый M4 extension отдельно учитывает durable lead после latest offer.

## Остаточные доказательные границы

1. **PostgreSQL доказательство прошло frozen memory/session boundary.** Четыре `pg` clients и фактические row-lock barriers доказали обе close-vs-create ordering, close-vs-feedback, close-vs-final и takeover-vs-stale-artifact; separate readback доказал idempotent atomic linked turn+message. Exhaustive stale-owner race для каждого вида durable mutation остаётся defense-in-depth follow-up, а не подтверждённым текущим дефектом.
2. **Rendered widget race/reload не выполнен после fixes.** M1 optimistic rollback, pending navigation recovery и M4 lead-offer consumption должны быть проверены через embedded `https://bakautprof.ru/`, с чтением UI после каждого хода.
3. **Post-fix deployment/live отсутствуют.** Current Railway marker/deployed commit, health/readiness и adaptive two-sided dialogues ещё не доказаны.
4. **Manufacturer registry консервативен.** Verified mapping сейчас покрывает FIRMAN/Honda/Husqvarna/STIHL. Другие бренды безопасно понижаются до secondary: это false-negative reachability risk, но не false authority.
Локальный code/DB signal: H1–H7/M1–M4 structurally resolved; AC5 и проверенные PostgreSQL race outcomes PASS. Primary release signal: не установлен до rendered-widget/live/deploy proof.
