## Implemented universal fixes

1. Search-first policy is fixed in repo instructions, behavior docs, runtime policy, writer clauses, and deterministic review. Missing data is not incompatibility. Failed/partial/timed-out/budget-skipped search is not exhausted research. Only a completed unresolved search may offer the final technical handoff, while preserving the candidate, confirmed facts, exact gap, phone request, and message/call choice.
2. Preliminary generator evidence collection is no longer denied because a load estimate is incomplete; final-fit safety remains deterministic. Reducer and planner now run as independent parallel Terra calls, persist independent checkpoints, and replan only when the applied ledger exposes a structured class/need/selection conflict.
3. Each open-ended strict product requirement can receive a typed per-product proof. Authoritative evidence may resolve a lower-authority conflict with a visible caveat. Cards deduplicate semantic model duplicates. Model indices `5000`, `2200`, and `2300` are not voltage/phase evidence; genuine bounded `О230` remains recognized.
4. Need selection updates are explicit (`preserve|replace|clear`) and can invalidate stale product IDs.
5. A persisted database deadline caps each turn at 60 seconds, reserves terminal time, and permits at most one atomic recovery attempt. Terminal degradation is durable and does not promise another automatic retry.
6. Reviewer rewrites are revalidated deterministically for unsupported identifiers, numbers, commercial commitments, and false lead confirmation. General delivery availability remains allowed; exact unsupported delivery promises remain blocked.
7. Lead success requires a durable dispatchable outbox. Cross-turn partial contacts live in a scoped 30-minute server draft, are redacted before the model, and preserve the original question. Public form completion atomically creates/reuses the lead, queues draft context, consumes the draft, and clears PII.
8. Structured JSON output exhaustion never causes an identical same-cap retry. A failed semantic-stage disposition is persisted; same-turn recovery repeats only the missing stage with a bounded 1.5x cap. The six-stage exceptional path now fits the logical model-call budget, while the persisted wall deadline remains authoritative.
